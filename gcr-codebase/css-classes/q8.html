Box-Sizing Comparison

See the difference between the default box model and border-box.

Default Box-Sizing

Width: 300px Padding: 30px Border: 5px

The default content-box model adds padding and border outside the declared width, making the total size larger than 300px.

Border-Box

Width: 300px Padding: 30px Border: 5px

With border-box, the declared width includes both padding and border, so the total width remains 300px.
