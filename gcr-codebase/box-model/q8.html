Content

The innermost area where text, images, and other elements are placed.

Padding

The space between the content and the border of an element.

Border

The visible line surrounding the padding and content areas.

Margin

The outer space that separates an element from other elements.

Box Sizing Comparison

Default Box Model

border-box

Width: 250px Padding: 25px Border: 5px

With border-box, padding and border are included inside the declared width.
